Calculated VE reference tables

A new Reference category in the table tree adds two synthetic, read-only grids for T1/logic-module cals:

  • Calculated VE (estimated) — the calibrator's own PEFTBL VE-vs-RPM curve, shaped across the load axis by MAPTBL (part-throttle fuel).
  • Calculated WOT VE (estimated) — the same shape using WOTTBL (full-throttle fuel) instead, matching how the ECU switches its fuel MAP source on TPS.

Both are computed by Spool, not decoded from the ROM — no injector size, displacement, or target-AFR assumption goes into them — and each carries its own note in the table view explaining what it does and doesn't account for. They're meant for eyeballing VE highs/lows while tuning, not as an absolute or certified VE%. Cals that don't carry the source curves (SBEC/T3 keeps fuel in native 2D grids with no separate pumping-efficiency curve) don't offer the Reference category at all.

Verified on the machine that built it: formatting, lints, the full workspace test suite, the interface-glyph check, and a signed release build. Both grids were confirmed against a real T1 calibration — sane, distinct values under each nav leaf — and a T3/SBEC calibration was confirmed to show neither.
