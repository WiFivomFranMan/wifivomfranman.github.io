Spool 26.1.0-rc.10

Windows. First public build since rc.4 — this covers everything from rc.5 through rc.10.

Download the installer (9.8 MB)

The installer is self-signed, so Windows SmartScreen warns on first run. Choose More info → Run anyway. Spool normally updates itself from within the app; this page is here so the release notes are readable without a GitHub account.

1984-86 two-chip ECUs (new)

Spool now opens and safely saves the 8 KiB calibrations from 1984-86 Turbo I logic modules, the generation that splits its calibration across two chips.

  • Saving is now correct. These ECUs check their calibration differently from 1987-and-later cals: there is no stored checksum byte, and the ECU sums both chips into one total. Earlier builds applied the newer scheme, which wrote to a filler byte, broke the real checksum, and still reported “checksum ok”. Spool now preserves the checksum on save and the indicator tells the truth.
  • A definition for the '85 Direct Connection intercooled cal (118) ships with the app, so a bare .bin with no sidecar opens with its tables named and grouped.
  • 129 of that definition's tables now carry real engineering units, read out of the disassembly rather than left as raw 0-255 counts: spark advance in degrees against MAP in psi, and thresholds in rpm, volts, degrees F and seconds.
  • Four spark and fuel curves were stored signed but described as unsigned, so high-boost retard was displaying as a large positive advance. Corrected.

V6 definitions

  • The naturally-aspirated 3.0 V6 definitions had been built against a turbo symbol file and described boost hardware the engine does not have. Those are corrected or held back.
  • WOT and part-throttle spark curves are labelled in rpm and degrees.
  • MAP axis ranges corrected.

Safeguards

  • The definition builder refuses to ship a definition whose tables do not decode where it claims they are.
  • Spool warns when a template does not fit the bin it was opened with, instead of showing plausible-looking nonsense.

macOS

Not part of this release. Mac testers stay on the still-hosted rc.2 DMG until the next build.
