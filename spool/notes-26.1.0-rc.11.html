Spool 26.1.0-rc.11

Windows. Fixes the update prompt in rc.10 — if you are on rc.10, this is the build to take.

Download the installer

The installer is self-signed, so Windows SmartScreen warns on first run. Choose More info → Run anyway.

The update prompt is usable again

In rc.10 the “Update Available” dialog laid its Download & Install button past the window edge — visible, but with its click area outside the window, so it could not be pressed or even highlighted. The prompt told you an update existed and gave you no way to accept it. The buttons now sit on two rows and all four are reachable.

Also fixed: View release notes and Open Releases Page pointed at the app's GitHub repository, which is private, so both returned a 404 for anyone without repository access. They now open a public notes page — this one.

Everything from rc.5 through rc.10

This is still the first stretch of work published since rc.4, so if you are coming from there:

1984-86 two-chip ECUs (new)

Spool opens and safely saves the 8 KiB calibrations from 1984-86 Turbo I logic modules, the generation that splits its calibration across two chips.

  • Saving is correct. These ECUs check their calibration differently from 1987-and-later cals: there is no stored checksum byte, and the ECU sums both chips into one total. Earlier builds applied the newer scheme, which wrote to a filler byte, broke the real checksum, and still reported “checksum ok”.
  • A definition for the '85 Direct Connection intercooled cal (118) ships with the app, so a bare .bin with no sidecar opens with its tables named and grouped.
  • 129 of that definition's tables carry real engineering units read out of the disassembly rather than raw 0-255 counts: spark advance in degrees against MAP in psi, and thresholds in rpm, volts, degrees F and seconds.
  • Four spark and fuel curves were stored signed but described as unsigned, so high-boost retard displayed as a large positive advance. Corrected.

V6 definitions

  • The naturally-aspirated 3.0 V6 definitions had been built against a turbo symbol file and described boost hardware the engine does not have. Those are corrected or held back.
  • WOT and part-throttle spark curves are labelled in rpm and degrees.
  • MAP axis ranges corrected.

Safeguards

  • The definition builder refuses to ship a definition whose tables do not decode where it claims they are.
  • Spool warns when a template does not fit the bin it was opened with.

macOS

Not part of this release. Mac testers stay on the still-hosted rc.2 DMG until the next build.
