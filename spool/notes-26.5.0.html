3D surface axes now match the calibration

The 3D view introduced last release spaced every column and row evenly, regardless of how much RPM or MAP that step actually covers. Most RPM×MAP tables aren't evenly spaced — the ECU's own breakpoints spend resolution where the calibrator needed it — so a table with, say, tight breakpoints below 2000 rpm and coarse ones above it had that entire low-rpm range compressed into a sliver of the plot, with a visible crease at the handoff that wasn't really in the calibration at all.

The mesh now follows each table's real, resolved axis values: a wide step draws wide, a narrow one draws narrow. Nothing about a table's stored values changed — only where each point sits in the 3D view, and the wireframe itself now shows you where a table actually carries resolution.

Calculated spark tables explain themselves

FullThrottleTotalTiming, PartThrottleTotalTiming, and similar tables under Calculated Tables aren't stored in the ROM — Spool builds them from the calibration's own advance and limit curves, the same way the ECU's warm-engine spark routine does. Opening one now shows, in plain language, exactly what went into the number.

Just as important is what's excluded: knock retard, adaptive retard, and the idle / start-run transfer paths are not part of this number, and a cold engine follows an entirely different curve that no calculated table covers. If you've been reading these tables as "what the engine runs," this is the correction — it's what the calibration asks for before anything downstream adjusts it.

Verified on the machine that built it: formatting, lints, the full workspace test suite (24 suites, 348 tests), the interface-glyph check, and a signed release build. Both changes were driven by hand against real calibrations — the axis fix against a 17×17 T3 fuel/timing table with genuinely uneven breakpoints on both axes, and the explanation text against a real T-SMEC calibration, confirming the full-throttle and part-throttle tables each name their own MAP source correctly.
