Spool 26.6.0

A new Chip Burner window programs ECU chips over a Moates Burn2, and a Connect bug that could get "stuck" on the first error is fixed.

Download for Windows

Windows only. There is no macOS build for 26.6.0; Mac users should stay on 26.1.0 until a signed DMG is published.
Windows is self-signed, so SmartScreen warns on first run: choose More info → Run anyway.

Chip Burner (Tools > Chip Burner)

Spool can now talk to a Moates Burn2 chip programmer directly: read a chip's contents, erase it, write a new image, and verify it came back blank before writing. Read, erase, write, and blank-check have each been run against real hardware — an SST27SF512 EPROM.

Connect no longer gets stuck on the first error

If a Connect attempt failed — wrong COM port, a chip or ECU that didn't answer — every later Connect click silently repeated that first error, even after switching to the correct port. The window looked ready to retry (it still showed "Connect", not "Disconnect"), but nothing happened. This affected both the new Chip Burner window and the ECU Flasher; both now retry properly.

Verified on the machine that built it: formatting, lints, the full workspace test suite, the interface-glyph check, and a signed release build. The Chip Burner's read/erase/write/verify-blank were each confirmed against a real Burn2 and a real SST27SF512 chip; the Connect-retry fix was reproduced and confirmed fixed against real Burn2 hardware, and compiles/tests clean for the Flasher side (not yet re-tested against a real ECU).
