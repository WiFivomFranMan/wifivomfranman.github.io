Spool 26.8.0

The table tree moves out of the sidebar and into a row of drill-down menus at the top, giving the full window width back to grids and graphs.

Download for Windows

Windows only. There is no macOS build for 26.8.0; Mac users should stay on 26.1.0 until a signed DMG is published.
Windows is self-signed, so SmartScreen warns on first run: choose More info → Run anyway.

Cascading table picker

The fixed 320px tree sidebar is gone. Picking a table is now a row of dropdowns across the top: choose a category, and the next level appears to its right, as deep as the calibration's own grouping goes. The OE definition library nests up to five levels (Boost Control / WG Control / T1 WG Control / T1 WGDC Lookup / table), and nothing assumes a fixed depth.

Everything that column used to hold moved with it. Tables, Changes, History and Diffs are now tabs in the top bar; the last three open a panel that floats over the detail pane while you're in that mode instead of permanently reserving width. Search lives in the picker row and its results now show each match's full path, so you can see where a table sits before you jump to it.

On a narrow window a deep chain folds its middle behind a … crumb, keeping the category you're in and the table you're on readable. Clicking it offers the alternatives at each hidden level, so nothing becomes unreachable.

More room for tall tables

The 3D view controls now share a row with the scale/offset tools rather than taking one of their own. On a tall grid — a 2-bar MAP scale runs 17+ rows — that recovered row is the difference between the whole table fitting on a maximized window and having to scroll it.

The Injector swap and MAP swap wizards move off the main toolbar into Tools, each in its own focused dialog, freeing that band for the picker row.

Fixes

  • Right-click menus now respond to clicks. Every context menu in the app was measuring a few pixels wide while painting at full size, so clicking an item landed just outside it and the menu simply closed. It went unnoticed because every affected action — Open, Copy, Revert, grid Copy/Paste/Undo — also has a double-click or Ctrl-key path that still worked.
  • Scale / Offset no longer appear where they do nothing. They were shown on the read-only Calculated VE reference views and on the "Select a table" screen, where pressing Apply silently did nothing at all.

Verified on the machine that built it: formatting, lints, the full workspace test suite, the interface-glyph check, and a signed release build. The picker was driven against a real T1 calibration — the five-level Boost chain, the overflow menu, search, right-click menus, and dragging the window to its minimum width.
