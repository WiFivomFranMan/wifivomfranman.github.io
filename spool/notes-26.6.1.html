Spool 26.6.1

Bug fix release: the Chip Burner window no longer clips its bottom card.

Download for Windows

Windows only. There is no macOS build for 26.6.1; Mac users should stay on 26.1.0 until a signed DMG is published.
Windows is self-signed, so SmartScreen warns on first run: choose More info → Run anyway.

Chip Burner window no longer clips its bottom card

The Chip Burner window (Tools > Chip Burner) had no scrollbar, so at smaller window sizes the last card — Write Chip, including the acknowledgement checkbox and the Write button — could be cut off with no way to reach it. The window now scrolls, so every card is reachable regardless of window size.

Verified on the machine that built it: formatting, lints, the full workspace test suite, the interface-glyph check, and a signed release build. The scroll fix was confirmed by driving the real app — opening Chip Burner, shrinking it, and scrolling down to the previously-clipped Write Chip controls.
