Spool 26.1.0

The first final release — and the first build for macOS since early July. Every version before this one was a release candidate.

If you are on the macOS build from July

You have been on 26.1.0-rc.2 for a month, because no Mac build was published between then and now — the releases in between were Windows only. Everything below is new to you.

Calibrations are identified for you

Open a factory .bin and Spool recognises it by fingerprint and names its tables automatically. No hunting for the matching template.

The definitions are read out of the disassembled code rather than guessed, and each one is checked against the calibration before it ships: a definition whose tables are not where it claims is refused. That check rejected several of our own definitions during development rather than let them mislabel your data.

Where a value has no real-world unit — a counter, a bitmask, a pulse count — it is left without one on purpose, instead of being given a plausible-looking scale that would be wrong.

1984-86 two-chip ECUs

Spool opens and safely saves the 8 KiB calibrations from 1984-86 Turbo I logic modules, the generation that splits its calibration across two chips and sums both into one checksum.

'85 Turbo I

165 tables in the '85 Turbo I definition now carry information derived from the code, up from 25 — including the wastegate duty scale, which is out of 200 rather than 255. Read the old way, the maximum-boost clamp appeared as 69% when it is really 88%.

The application

Separate windows for Cal Explorer, Log Viewer, Diagnostics, Flasher and Live Logger, each with its own menus, each remembering where you left it.

Undo, redo and change review — see what you changed, revert a single cell, and compare against the original in the editor.

Updates from inside the app. Spool checks for a new version, downloads it, and verifies the download before opening it.

Appearance

Fields and buttons now line up on a shared centreline instead of being different heights, and they are sized the same way on both platforms. The green accent now marks the primary action, the field you are typing in, and the current selection — previously it appeared almost nowhere.

macOS 26 fix

On macOS 26 and later the title bar rendered as clear glass, showing the desktop through it and leaving the window title unreadable. Fixed.

Known issues

Spool does not tell you which template it used. If a .tbl file sits next to your .bin with the same name, that file wins over the built-in definition library and you get the older names, with nothing on screen indicating a choice was made. If names look wrong, copy the .bin to an empty folder and open it from there. A fix is in progress.

macOS is Apple Silicon only. Intel Macs are not supported.

Dropdowns, checkboxes and sliders still use the operating system's own styling and look slightly different from the rest of the controls.

Found something wrong? The calibration data matters more than the app — if a table looks mislabelled or a value decodes oddly, please say so, with the calibration ID.
