Spool 26.2.1

A bug fix: the Flasher window could reopen too small to reach its Connect button.

Download for Windows

Windows only. There is no macOS build for 26.2.1; Mac users should stay on 26.1.0 until a signed DMG is published.
Windows is self-signed, so SmartScreen warns on first run: choose More info → Run anyway.

The Flasher could open with Connect unreachable

In the Flasher window, the Connect button could render as a single clipped letter at the right edge of the connection row — or be pushed off the window entirely. With Connect unreachable, the window could not do the one thing it exists for.

Widening the window by hand brought the button back, but nothing indicated that was the problem, so the window simply looked broken.

Why it kept happening

Spool remembers each window's size between sessions. The Flasher's remembered size was smaller than its contents actually need, and that saved size was being restored without being checked against the window's own minimum. So every launch reopened it at the same unusable width, and resizing it did not stick.

What changed

  • The Flasher's minimum width now covers its full connection row.
  • Every window that remembers its size is now clamped to that window's minimum when restored, so a too-small saved size cannot come back.

The second point is the one that actually fixes it, and it applies to all six tool windows that remember their geometry — the Flasher was simply the one where a control happened to sit at the clipped edge. If you had the Flasher open small, it reopens wider on this build.

Nothing about flashing itself changed

The write safeguards are untouched. A destructive write still requires all three: a checksum-valid bin, a ROM backup saved in that session, and the confirmation box ticked. The read-only ROM pull remains the recommended first step, and the reminder that this path is not hardware-verified is still shown.

Housekeeping

Contributor documentation now describes one consistent local check, separated into a fast pre-push gate and a fuller pre-release gate. This has no effect on the application.

Verified on the machine that built it: formatting, lints, the full workspace test suite (24 suites, 330 tests), the interface-glyph check, and a signed release build driven by hand — the Flasher window was reopened from the previously broken saved size and measured to confirm Connect renders in full.
